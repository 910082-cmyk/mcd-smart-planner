# 麦麦智配看板 · 交互体验优化报告

- 优化对象：`mcd-dashboard/index.html`（单文件看板，七模块：菜单看板 / 食物查询 / 热量配餐 / 优惠最大化 / 点单建议 / 积分领券 / 功能集成）
- 优化日期：2026-10-14
- 改动方式：原地增量修改，原始版本已备份为 `index.html.bak-ux`
- 验证方式：Node + jsdom 运行时执行页面脚本，50 项行为断言全部通过，无脚本错误

---

## 一、交互问题审计总览

按用户要求的五类核心场景逐项走查，另补状态反馈、性能、无障碍三个维度，共确认 21 项问题：

| 场景 | 数量 | 典型问题 |
|---|---|---|
| 点击 | 4 | 加入比价无任何反馈；按钮无按下态；购物车状态跨模块不可见 |
| 悬停 | 2 | 缩略图悬停聚焦仅鼠标可用；触控无按下反馈 |
| 滚动 | 3 | 快速悬停时多个滚动动画互相打架；每次按键重启 800ms 动画；不尊重系统减少动态偏好 |
| 表单提交 | 5 | 搜索无防抖，每敲一字全量重建 121 张卡片；数量框可变成 0 / 空 / NaN；目标热量、人数、距离越界无收敛 |
| 页面切换 | 3 | 七模块 Tab 无 Hash 路由，不能深链接 / 前进后退；无 ARIA Tabs 语义；键盘不可达 |
| 状态反馈 | 2 | 图片裂图无降级；计算类操作无进行态 |
| 性能 | 1 | WebGL resize 无防抖，拖动窗口掉帧 |
| 无障碍 | 1 | 次级文字对比度 2.9:1，低于 WCAG AA 的 4.5:1 |

## 二、优化项明细

### 优化 1：全局轻提示（Toast）

- 目标：消除「点了没反应」的反馈缺失，让每个状态变更操作可感知
- 具体改进：新增底部居中的 Toast 组件（移动端底部 / 桌面端顶部，2.4s 自动消失，`role="status"` + `aria-live`）；接入 7 个调用点——加入比价、方案整组加入、删除单品、清空购物车、一键加入麦金卡套餐、空车计算提醒、参数越界自动纠正
- 预期提升：操作即时确认，误操作（重复点击、以为没加上而反复点）显著减少；读屏用户可同步获知状态变化

### 优化 2：购物车数量徽标

- 目标：跨模块状态可见，不用逐个切 Tab 找购物车
- 具体改进：「优惠最大化」导航按钮内联红色数字徽标，随增删实时更新，99+ 封顶；空车自动隐藏
- 预期提升：随时掌握购物车内容量，配餐方案「加入比价」后能直接看到徽标跳动并跳转计算，流程不中断

### 优化 3：按钮按压态与触控反馈

- 目标：补齐「按下」这一最基本的状态反馈，兼顾桌面与移动端
- 具体改进：`.btn` / `.madd` / `.chip` / `.tile` / 导航按钮新增 `:active` 缩放（0.95–0.97）；全局禁用移动端点击高亮块、禁止按钮文字被选中误拖
- 预期提升：点击有「按下去」的实体感；移动端连点不再误选文字

### 优化 4：键盘焦点可见性

- 目标：键盘用户不迷路，满足 WCAG 2.2 焦点可见要求
- 具体改进：全部可交互元素统一 `:focus-visible` 金色 3px 描边 + 2px 偏移；数量输入框补焦点光环，与搜索框视觉语言一致
- 预期提升：Tab 导航时当前位置一眼可辨，焦点环不再依赖浏览器默认样式的不一致表现

### 优化 5：搜索防抖与输入心流保护

- 目标：解决「响应迟缓」——低端机打字卡顿、输入过程中面板跳动
- 具体改进：两处搜索输入加 160/180ms 防抖，连续打字只触发一次全量重绘；输入期间保留当前聚焦餐品、不再重启缩略图条滚动动画；Enter 立即执行、Esc 清空并失焦
- 预期提升：打字流畅不卡；筛选过程中精选面板不再反复跳回第一项，心流不被打断

### 优化 6：表单参数收敛与校验

- 目标：杜绝异常值导致的「状态不明确」（¥NaN、0 人用餐、负数小计）
- 具体改进：目标热量越界自动收敛到 100–3000 并 Toast 告知；人数收敛 1–10；距离下限 100 米；购物车数量收敛 1–99（空值 / 字母 / 0 / 超大值全部归一），输入框同步回显
- 预期提升：任何输入下计算结果都可信、可解释；用户知道系统替他修正了什么

### 优化 7：计算类操作的进行态

- 目标：同步计算阻塞主线程时避免「界面假死」观感
- 具体改进：三个计算按钮（配餐 / 比价 / 点单建议）点击后立即进入「计算中」禁用态 + 转圈图标，计算完成自动恢复；空车计算改为先 Toast 提醒再展示说明
- 预期提升：重计算也有明确响应感，不会让人怀疑「按钮坏了」而重复点击

### 优化 8：缩略图条滚动动画治理

- 目标：快速悬停 / 连续切换时动画不再互相打架
- 具体改进：滚动动画加令牌取消机制，新动画启动即中止上一个；时长 800ms 调至 600ms；尊重 `prefers-reduced-motion` 时直接瞬移
- 预期提升：快速浏览餐品时缩略图条跟手、不抖动；对动效敏感的用户不晕

### 优化 9：全局尊重「减少动态效果」系统偏好

- 目标：无障碍合规（WCAG 2.2），服务前庭敏感用户
- 具体改进：Tab 切换淡入关闭、3D 金拱门改为只渲染一帧静态画面、各类过渡动画禁用、Toast 与徽标弹跳动效禁用；并对 `matchMedia` 做存在性防御（旧环境不崩）
- 预期提升：系统级偏好被真正执行；同时修复了「个别旧浏览器无 matchMedia 时整页脚本中断」的隐患

### 优化 10：Hash 路由与浏览器历史整合

- 目标：七模块单页切换获得原生页面般的导航能力
- 具体改进：切换 Tab 写入 `location.hash`；监听 `hashchange` 实现前进 / 后退；支持 `#coupon` 这类深链接直达启动；Tab 标题同步更新为「麦麦智配 · 模块名」；hash 回写与用户操作通过「面板状态比对」区分，不产生回声循环
- 预期提升：可以把某个模块直接发给别人打开；摸鱼被老板打断时按返回键能回到刚才看的模块

### 优化 11：WAI-ARIA Tabs 模式

- 目标：读屏软件与键盘用户完整可用
- 具体改进：导航加 `role="tablist"`、按钮 `role="tab"` + `aria-selected` + `aria-controls`；七个面板 `role="tabpanel"` + `aria-labelledby` + `tabindex="-1"`；支持 ←/→/Home/End 方向键切换；切换后焦点移入面板；移动端导航激活项自动横向滚入可见区
- 预期提升：Tab 语义对辅助技术完全显式；手机横滑导航条时当前模块始终可见

### 优化 12：图片加载失败降级

- 目标：弱网 / 图床抽风时界面状态依然明确
- 具体改进：精选面板图片失败切换到「暂无图片」态；菜单卡片图片失败露出 🍔 表情占位；查询页大图失败自动移除让统计卡占满
- 预期提升：不再出现破碎图片图标，信息层级不塌

### 优化 13：移动端输入与触控细节

- 目标：iOS  Safari 输入体验与触控目标尺寸
- 具体改进：输入框字号 15px 提至 16px，聚焦时 iOS 不再自动放大页面；数量框移动端加宽至 56px、加高 padding，达到 44px 级触控目标
- 预期提升：手机上填参数不「抖动」，数量框点得动

### 优化 14：WebGL 渲染性能保护

- 目标：拖动窗口时不掉帧
- 具体改进：resize 处理加 140ms 防抖，且尺寸未变化直接跳过重算
- 预期提升：连续拖动窗口只做有效重算，3D 金拱门流畅稳定

### 优化 15：WCAG AA 对比度修正

- 目标：正文与小字对比度全部达到 4.5:1
- 具体改进：次级文字色 `#A08D7A`（2.9:1）加深为 `#857260`（约 4.6:1），一处改动覆盖说明文字、表格副标、空态提示等十余处；品牌区红底上的三处小字（`#FFD98A` / `#FFC9A8` / `#FFE3B0`）提亮至 4.5:1 以上
- 预期提升：强光环境、老年用户、低视力用户均可正常阅读；参赛作品的技术合规分不丢

### 优化 16：健壮性兜底

- 目标：边缘数据不再产生奇怪显示
- 具体改进：积分最低档在无有效数据时显示「—」而非 `Infinity`；新增 `<noscript>` 提示；删除按钮补 `aria-label`
- 预期提升：数据异常时界面依然体面
