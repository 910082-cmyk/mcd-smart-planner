# 麦麦智配 · 麦当劳消费决策看板

> 基于麦当劳官方 MCP 能力的 Web 可视化决策助手 —— 把分散的菜单、营养、价格、门店数据，整合为「吃什么、怎么吃最划算、热量是否超标」的一站式答案。

「麦麦智配」是为 **M-CODE 2026 麦当劳程序员创意开发大赛** 开发的参赛项目。它以麦当劳中国官方 MCP Server（`mcp.mcd.cn`）为数据底座，提供七大决策模块，并通过程序化 3D 品牌视觉（Three.js 金拱门舞台）强化传播力。

## 核心特性

- **菜单看板**：121 项在售餐品，严格按麦当劳官方 15 大分类顺序排列，支持打字搜索与分类浏览，商品图 100% 实拍抠图。
- **食物查询**：按名称 / 分类 / 标签快速检索单品的价格、热量、营养与图片。
- **热量配餐**：给定目标热量（如 500 / 800 kcal），自动生成多套搭配方案，并标注每项热量与单价。
- **优惠最大化**：基于真实优惠券与立省标签，自动计算「已省最多」的组合，跨模块联动结算条实时显示省了多少。
- **点单建议**：结合预算、人数、场景（堂食 / 外带 / 出行）给出推荐组合。
- **积分领券**：展示积分折算价值、距最低兑换档进度与可领券种。
- **功能集成**：一览本项目实际调用的麦当劳 MCP 工具与字段。

## 技术栈

- 单页 **HTML + 原生 JavaScript**，零构建、零框架依赖，可直接双击打开或静态托管。
- **Three.js r128（本地化 `vendor/`）**：金拱门 3D 舞台（环境反射、体积光、粒子尘埃、拖拽旋转），已内置 WebGL 降级方案（降级为官方矢量 M 标志 + 2D 大图，绝不白屏）。
- **官方品牌资产**：麦当劳官方矢量 M（`assets/mcd-logo.svg`，simple-icons CC0），品牌色经官方资料核验（`#FFC72C` / `#DA291C`）。
- 数据默认**离线内联**（`seed-data.json` 已固化为页面内 `SEED`），无需联网即可演示；亦支持通过麦当劳 MCP 实时刷新。

## 快速开始

### 方式一：本地直接打开
双击 `index.html` 即可在浏览器中使用全部功能（数据已内联，无需联网）。

### 方式二：本地静态服务（推荐，避免浏览器 file:// 限制）
```bash
cd mcd-dashboard
python -m http.server 8080
# 浏览器访问 http://localhost:8080/index.html
```

### 配置麦当劳 MCP（用于实时刷新数据，可选）
1. 在麦当劳 MCP 控制台申请 Token。
2. 复制配置示例并按需填写：
   ```bash
   cp mcp-config.example.json mcp-config.json
   # 将 ${MCD_MCP_TOKEN} 替换为你的真实 Token（建议用环境变量注入，勿入库）
   ```
3. 在 WorkBuddy「连接器」中配置 `mcd-mcp`，即可让 AI 实时调用麦当劳 MCP 工具。

## 使用示例

1. 打开看板，顶部为 **3D 金拱门品牌舞台**（可拖拽旋转）。
2. 进入「菜单看板」：输入关键词或点击分类，浏览 121 项餐品。
3. 进入「热量配餐」：设定目标热量与人数，生成多套低卡搭配。
4. 进入「优惠最大化」：系统自动给出省得最多的组合，底部结算条实时显示「已省 / 合计」。
5. 收藏到购物车，跨模块统一结算与比价。

界面示例见 `hero-sample-light.png` / `hero-sample-dark.png` / `hero-sample-mobile.png`。

## 目标用户

- **注重性价比的消费者**：想用最少钱吃到满足的一餐。
- **健身 / 控卡人群**：需要精确掌控每餐热量与营养结构。
- **上班族与学生**：在有限预算与时间内快速决策。
- **麦当劳爱好者与开发者**：想了解官方 MCP 能力如何落地为实用产品。
